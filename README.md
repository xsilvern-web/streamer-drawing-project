# streamer-drawing-project
개인용 그림후원 프로그램 서버

## GIF 불러오기 회귀 검증

Node.js 18 이상에서 추가 패키지 없이 실행합니다.

```sh
node --test tests/gif-import.test.cjs tests/gif-groups.test.cjs
```

전체 파일 읽기와 트랙 메타데이터 준비를 각각 지연시켜,
준비 전에 프레임 수를 확정하지 않는지, 전체 프레임 및 재생 시간이 보존되는지,
오류 발생 시 리소스가 정리되는지 검증합니다.
브라우저 수동 검증은 Chrome 또는 Edge의 `/draw` 화면에서 이미지 불러오기로
GIF를 선택한 뒤 프레임 수와 각 프레임의 노출 시간을 확인합니다.

## GIF 전체 편집

GIF를 불러오면 첫 프레임이 선택되고 오른쪽에 **GIF 전체 편집** 패널이 표시됩니다.
기본으로 켜진 **위치·크기 함께 조정** 상태에서 그림을 드래그하거나 모서리를 조절하면
같은 GIF의 모든 프레임에 적용됩니다. Shift를 누르고 모서리를 조절하면 비율을 유지합니다.
체크를 끄면 프레임별로 조절할 수 있고, 다시 켜면 현재 프레임의 위치와 크기로 맞춥니다.

**GIF 전체 확정** 버튼이나 Enter로 같은 GIF의 모든 프레임을 한 번에 확정할 수 있습니다.
확정 전 파일을 저장해도 GIF 그룹과 배치가 유지되어, 다시 열어 전체 편집을 이어갈 수 있습니다.
